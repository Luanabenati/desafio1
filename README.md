# 🎮 GameZone Retro

## 📋 Sobre o Projeto

O **GameZone Retro** é uma página HTML criada para representar uma loja especializada em **jogos clássicos e consoles retrô**.

O projeto foi desenvolvido como parte de um **Mini Desafio HTML**, com o objetivo de praticar os principais elementos da linguagem HTML de forma simples, organizada e funcional.

---

## 🎯 Objetivo

Criar uma página promocional compacta para a **GameZone Retro**, utilizando apenas **HTML puro**, com no máximo 50 linhas de código.

A página apresenta informações sobre a loja, consoles disponíveis, produtos e seus respectivos preços.

---

## 🕹️ Conteúdo da Página

A página contém:

* 🎮 Nome e apresentação da loja
* 📝 Texto com formatação em **negrito** e *itálico*
* 🔗 Link interno para a tabela de preços
* 🌐 Link externo para o Instagram
* 🖼️ Imagem relacionada ao tema retrô
* 🕹️ Lista de consoles disponíveis
* 💰 Tabela com jogos e preços
* ©️ Rodapé com o nome da loja

---
